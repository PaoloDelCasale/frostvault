### M-A1: Lexicographic operating-window comparison — Auditor 1 only

- **Claim:** `_normalize_windows` compares raw `start`/`end` strings at `operation_policies.py:96-97` after parsing ints for shape only; non-padded inputs that pass `OperatingWindowModel` (`min_length=4`) can reject valid windows and accept inverted ones, violating REQ-012 CoS 2–3.
- **Verification probe (confirmation — assertion that FAILS under desired behavior / PASSES as proof of bug on current code):**

```python
# Confirmation proof: inverted non-padded window is accepted (bug exists)
from app.services.operation_policies import _normalize_windows
_normalize_windows([{"weekday": 1, "start": "10:00", "end": "9:30"}])
# Current: returns ok (no ValueError)
# Evidence line 96: `if start >= end:` — `"10:00" >= "9:30"` is False
# Desired: ValueError("operating window start must be before end")
```

- **Verdict:** **CONFIRMED** → **BUG-007** (Medium, REQ-012)
- **Category:** Real code bug
