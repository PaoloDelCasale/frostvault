# BUG-004: csrf_token_for ignores session_version force-logout

> Generated by [Quality Playbook](https://github.com/andrewstellman/quality-playbook) v1.5.6 — Andrew Stellman
> Date: 2026-07-23 · Project: FrostVault

## 1. Summary

Force-logout bumps `session_version` which `resolve_session` honors, but CSRF lookup still returns the token.

## 2. Spec reference

- Requirement: REQ-008
- Behavioral contract quote: "CSRF lookup returns None when session_version diverges"
- REQ-008: CSRF acceptance should fail closed on version skew, matching resolve_session (`sessions.py:95-96`).

## 3. The code

`csrf_token_for` SELECT omits session_version (`sessions.py:123-137`).

## 4. Observable consequence

CSRF middleware can accept tokens for force-logged-out sessions. Endpoints still reject via `current_user`, so this is defense-in-depth, not a present auth bypass.
