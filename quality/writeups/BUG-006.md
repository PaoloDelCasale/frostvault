# BUG-006: Startup cleanup destroys free-space claim files before reconcile

> Generated by [Quality Playbook](https://github.com/andrewstellman/quality-playbook) v1.5.6 — Andrew Stellman
> Date: 2026-07-23 · Project: FrostVault · Source: Spec Audit

## 1. Summary

A crash mid free-space claim can permanently lose the only Local Copy because startup deletes `.cleanup-*.tmp` before reconciliation can restore it, then marks the Job completed.

## 2. Spec reference

- Primary requirement: REQ-009
- CoS: claim must restore on verification failure; salvageable claim path must remain available.

## 3. The code

- `is_restore_temporary_name` includes `CLEANUP_TEMPORARY_RE` at `app/storage.py:353-357`
- `cleanup_abandoned_restore_files` unlinks matching names at `app/storage.py:1028`
- Lifespan runs cleanup before reconcile at `app/main.py:160-161`
- Reconcile free-space missing path marks completed at `app/storage.py:1092-1109` without `restore_claimed_local_copy`

## 4. Observable consequence

Crash between `local_path.rename(claimed_path)` and successful unlink → restart deletes claim → Job completed as “Local space freed” → Local Copy gone without verified free-space success path.

## 5. Depth judgment

REQ-009 is written around the worker claim/restore path; restart composition silently voids that invariant. Auditor 2 found it; executable probes confirmed.

## 6. The fix

Proposed change (prefer excluding cleanup claims from abandoned-restore cleanup, and/or restore-before-complete in reconcile):

```diff
diff --git a/app/storage.py b/app/storage.py
--- a/app/storage.py
+++ b/app/storage.py
@@ def cleanup_abandoned_restore_files
-                if is_restore_temporary_name(entry.name):
+                # Free-space .cleanup-*.tmp claims are salvage copies — do not
+                # unlink them here; reconcile_interrupted_jobs owns restore.
+                if (
+                    RESTORE_TEMPORARY_RE.fullmatch(entry.name) is not None
+                    or VERIFY_TEMPORARY_RE.fullmatch(entry.name) is not None
+                ):
                     try:
                         entry.unlink(missing_ok=True)
```

Also teach reconcile free-space missing-path to search for `.cleanup-*.tmp` siblings and call `restore_claimed_local_copy` before marking completed.
