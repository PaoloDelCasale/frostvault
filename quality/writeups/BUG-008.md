# BUG-008: Cloud scan forks Vault File identity after rename

> Generated by [Quality Playbook](https://github.com/andrewstellman/quality-playbook) v1.5.10 — Andrew Stellman

## 1. Summary

Cloud rediscovery of a renamed file's old S3 key mints a new Vault File because identity create runs before object_key dedupe and only matches current paths.
